# 🌐 David Apryansyah - Personal Portofolio & Resume

Selamat datang di repository portofolio web saya! Website ini dirancang secara modern dan elegan menggunakan konsep *dark theme* dengan aksen warna teal untuk menampilkan profil profesional, pengalaman kerja, proyek pengembangan web, dan keahlian teknis saya.

🚀 **Live Demo:** [https://davidaprr.github.io/portofolio.me](https://davidaprr.github.io/portofolio.me)

---

## 📌 Fitur Utama

- **Responsive Design:** Tampilan adaptif yang nyaman diakses melalui smartphone maupun layar laptop/desktop.
- **Interactive Portfolio (`index.html`):** Berisi ringkasan profil, riwayat karir, proyek *full-stack*, dan daftar keahlian teknis.
- **Printable CV / Resume (`cv.html`):** Halaman CV siap cetak (A4 format) yang dapat diunduh langsung menjadi file PDF.
- **Direct Contact Links:** Terhubung langsung ke WhatsApp, LinkedIn, Instagram, dan GitHub.

---

## 🛠️ Teknologi yang Digunakan

- **HTML5 & CSS3**
- **Tailwind CSS** (via CDN untuk styling responsive dan modern)
- **JavaScript**
- **FontAwesome** (untuk ikon antarmuka)
- **GitHub Pages** (sebagai layanan *hosting*)
